# ShopNET Movies — Phase Gates

## Gate 0 — Analysis
Deliver:
- repository assessment
- architecture map
- risks
- dependencies
- missing requirements
- model recommendation

Owner approval required.

## Gate 1 — Foundation
Deliver:
- project structure
- tooling
- base app
- configuration
- CI/testing foundation

Owner approval required.

## Gate 2 — Identity
Deliver:
- users
- authentication
- authorization
- sessions/tokens
- security tests

Owner approval required.

## Gate 3 — Domain
Deliver:
- projects
- scripts
- characters
- scenes
- media metadata
- jobs
- database migrations

Owner approval required.

## Gate 4 — AI Gateway
Deliver:
- provider interfaces
- adapters
- usage tracking
- cost tracking
- retries
- fallback mechanisms

Provider decisions must already be approved.

## Gate 5 — Generation
Deliver:
- image generation
- text-to-video
- image-to-video
- Omni Flash adapter if selected
- job processing
- media storage

Owner approval required.

## Gate 6 — Social
Deliver:
- OAuth
- connected accounts
- single/multi-platform publishing
- scheduling
- retry/status

Owner approval required.

## Gate 7 — Billing
Deliver:
- subscriptions
- payments
- webhook handling
- credits
- idempotency
- usage accounting

Owner approval required.

## Gate 8 — Security & resilience
Deliver:
- rate limits
- abuse prevention
- DDoS/WAF integration points
- security review
- secret audit
- dependency audit

Owner approval required.

## Gate 9 — QA
Deliver:
- unit/integration/e2e tests
- browser verification
- load-oriented checks
- regression suite
- bug fixes

Owner approval required.

## Gate 10 — Production readiness
Deliver:
- deployment plan
- environment checklist
- monitoring
- backups
- rollback
- incident procedures

Owner approval required.
