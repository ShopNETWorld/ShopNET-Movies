# Prompt 08 — Security, Abuse Prevention and Resilience

Perform a security-focused implementation and audit.

Cover:
- authentication
- authorization
- secrets
- API abuse
- rate limiting
- generation abuse
- upload security
- SSRF
- prompt injection
- OAuth tokens
- payment webhooks
- idempotency
- dependency vulnerabilities
- audit logs
- DDoS/WAF integration points
- safe error handling

Do not weaken controls to make tests pass.

Create:
`docs/PHASE-08-SECURITY-REPORT.md`

Classify findings by severity.

Fix approved issues and retest.

STOP at the phase gate.
