# Prompt 10 — Production Readiness

Do not deploy automatically.

Review:
- environment configuration
- secrets
- database migrations
- backups
- monitoring
- logging
- alerting
- rate limits
- WAF/CDN/DDoS controls
- storage
- queues/workers
- payment configuration
- OAuth redirect URLs
- provider API limits
- cost controls
- rollback plan
- incident response

Produce:
`docs/PRODUCTION-READINESS-REPORT.md`

Do not execute production deployment.

STOP and wait for explicit owner authorization.
