# Prompt 01 — Foundation

Precondition:
The owner has reviewed Prompt 00 and approved Phase 1.

Before coding:
1. State the currently selected model.
2. Confirm this phase only.
3. If you believe a different model is materially better, stop and request the change using the MODEL CHANGE REQUIRED format.

Implement only the approved project foundation:
- repository structure
- application scaffolding
- configuration
- environment handling
- linting
- formatting
- type checking
- test framework
- basic CI structure where approved
- logging foundation
- error-handling foundation

Do not implement:
- payment logic
- social publishing
- production AI provider calls
- destructive database migrations
- production deployment

Run relevant checks.

Create:
`docs/PHASE-01-REPORT.md`
